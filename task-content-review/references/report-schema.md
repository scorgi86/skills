# Схема Карточки Заключения Разработки

Использовать только эту структуру:

```text
ЗАКЛЮЧЕНИЕ РАЗРАБОТКИ

Автор Заключения Разработки: <фамилия и имя или полное ФИО>.

Заключение: <значение из development-conclusion-rules.md>.

Замечания:

1.
Требование или его идентификатор: <FR/NFR ID либо однозначная формулировка>.
Замечание: <какого описания не хватает>.
Допущение: <только для некритичного замечания>.
Статус: <значение из development-conclusion-rules.md>.
```

Если замечаний нет, не выводить заголовок `Замечания`.

Поле `Допущение` не выводить для замечания, которому оно запрещено нормативными правилами.

Не включать внутрь Карточки:

- признак черновика, контекст проверки и служебные идентификаторы;
- процент или матрицу полноты;
- готовность к финальной приёмке;
- рекомендации реализации или тестирования;
- оценку разработки, роли, часы и допущения к оценке;
- дополнительные разделы A/B/C.

Признак черновика, ограничения и контекст проверенного объёма размещать только во внешней оболочке результата по `workflows/06-report.md`.
