# Codex Skills

Набор пользовательских скилов для Codex, предназначенных для анализа кодовой базы, планирования задач и подготовки изменений.

## Состав

### `feature-usage-inventory-ast`

Поиск прямых и косвенных использований функциональности в кодовой базе. Использует текстовый поиск, AST-анализ и GitNexus для построения карты зависимостей и проверки полноты исследования.

### `legacy-safe-mode`

Строгий процесс внесения изменений в крупные legacy-проекты: предварительный анализ, минимальные правки, проверка рисков и согласование перед изменением кода.

### `pr-message`

Создание ориентированного на ревьюера описания Pull Request на основе Git-изменений. Поддерживает быстрый, семантический и глубокий режимы анализа.

### `resolve-task-plan`

Пошаговый разбор продуктовой задачи: проверка требований, подготовка карточки решения, исследование затронутых механизмов и составление проверяемого плана реализации.

### `trace-ai-actions`

Показывает пользователю краткий журнал действий AI: команды, обращения к инструментам, изменённые файлы, решения и результаты проверок. Может сохранять очищенный журнал в формате JSONL.

## Установка

Скопируйте нужные каталоги в директорию пользовательских скилов Codex:

```powershell
Copy-Item -Recurse `
  .\feature-usage-inventory-ast, `
  .\legacy-safe-mode, `
  .\pr-message, `
  .\resolve-task-plan, `
  .\trace-ai-actions `
  "$env:USERPROFILE\.codex\skills"
```

После копирования перезапустите Codex или откройте новую сессию.

## Использование

Скил можно вызвать по имени в запросе:

```text
Используй $feature-usage-inventory-ast и найди все использования CommentData.
```

```text
Используй $resolve-task-plan и подготовь план решения задачи.
```

```text
Используй $pr-message и сформируй описание Pull Request.
```

Подробные инструкции и ограничения находятся в файле `SKILL.md` каждого скила.

## Требования

Для работы вспомогательных скриптов могут потребоваться:

- Node.js;
- Git;
- GitNexus — для сценариев AST-анализа;
- репозиторий с доступной историей Git.

Конкретные требования зависят от выбранного скила.

## Структура скила

Типичная структура каталога:

```text
skill-name/
├── SKILL.md          # инструкция и условия применения
├── agents/           # метаданные для Codex
├── references/       # контракты, шаблоны и справочные материалы
├── scripts/          # вспомогательные инструменты
└── steps/            # отдельные этапы workflow
```

## Разработка

Перед публикацией изменений рекомендуется:

1. проверить корректность `SKILL.md`;
2. запустить тесты изменённых скриптов;
3. убедиться, что в репозиторий не попали `node_modules`, временные файлы, журналы и резервные копии;
4. проверить скил в новой сессии Codex.

## Лицензия

Условия использования и распространения пока не определены.
